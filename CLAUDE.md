# Правила проекта

Русский перевод текста, который добавляют моды Mass Effect 3 Legendary Edition.

## С чего начинать сеанс

```
python tools/check.py --build
git log --oneline -3
```

Ревизор сам покажет, что не в порядке, и положит полный отчёт в `work/check.txt`.
Осматривать проект не нужно.

## Что переводим и что не трогаем

**Переводим** только текст, который добавляют моды, — он лежит в их файлах
`<Имя_DLC>_RUS.tlk`.

**Не трогаем никогда:**
- ванильный текст игры,
- озвучку,
- текстуры и модели,
- скрипты модов.

**Намеренно оставляем по-английски:** названия самих модов, титры с именами
авторов, названия песен в плеере. Список таких строк — в `tools/glossary.json`,
раздел `не_переводим`.

## Стиль

Текст выдержан под **официальную локализацию трилогии**. Терминология не
придумывается, а сверяется со словарём в `reference/` — там примерно
100 000 пар «оригинал → официальный русский», собранных из LE1, LE2, LE3 и
всех DLC. Поиск по словарю: `python tools/lookup.py <слово>`.

- **Буква «ё» не используется.** В официальном переводе её нет.
- **Commander Shepard — «капитан Шепард»**, не «коммандер».
- **Кавычки прямые** `"…"`, не угловые. В официальном переводе прямые
  в 3411 строках против 8 с угловыми.
- Имена, названия кораблей, оружия, планет и организаций — из игры,
  а не переведённые на слух.

Проверенные термины и запрещённые формы — в `tools/glossary.json`.
Нашли новый — вносим туда, а не держим в голове.

## Обращение к игроку

Главное правило, которое легко нарушить незаметно.

**К человеку перед экраном обращаться нельзя.** Интерфейс, окна настроек,
журнал заданий и кодекс пишутся безлично. Описание настройки говорит,
**что делает опция**, а не **что сделать игроку**:

- «Убедись, что…» → «Стоит проверить, что…»
- «Задай…» → «Дает возможность задать…»
- «Настрой письма на…» → «Настраивает письма на…»
- «Выбери…» → «Позволяет выбрать…»
- «Сохранись и перезагрузи игру» → «Потребуется сохраниться и перезагрузить игру»

Причина: мы не знаем, кто сидит перед экраном. Человек может играть за
женского Шепард, будучи мужчиной, и наоборот.

**А вот персонажи игры род сохраняют.** В письмах, репликах и предысториях
Гаррус говорит о себе в мужском роде, Лиара в женском, и к Шепард персонажи
обращаются по её полу — так задумано авторами. Повелительное наклонение
в письме от Хакета — это он пишет Шепард, и трогать его не надо.

Строки, где повелительное наклонение законно, перечислены в
`tools/glossary.json`, раздел `повелительное_разрешено`.

## Мужской и женский Шепард

Перевод собирается в двух вариантах. Основной — женский, он лежит в
`translation/`. Правки под мужского Шепарда описаны таблицей в
`tools/mkmale.py` и собираются в `translation_male/`.

Различаются только те строки, где русский требует рода от самой Шепард:
письма и реплики, обращённые к ней. Всё остальное одинаково.

## Как устроены файлы

```
source/        выгрузка модов из игры: английский текст и собственный русский мода
translation/   наш перевод, по одному файлу на мод
translation_male/  правки под мужского Шепарда
reference/     словарь из официальных локализаций
dist/          готовые файлы в структуре игры, как в релизе
tools/         скрипты
work/          черновики и отчёты, в репозиторий не идут
```

`source/` и `reference/` в репозиторий не кладём: это чужая интеллектуальная
собственность. Восстанавливаются скриптами `tools/dump.py`,
`tools/build_le1_ref.py`, `tools/build_le2_ref.py`, `tools/build_dlc_ref.py`.

**Собственный русский мода.** Некоторые моды держат в своём `RUS.tlk` не
перевод, а устаревшую английскую редакцию строк. Поэтому строка считается
переведённой, только если в ней действительно есть кириллица —
`common.has_russian()`. Из-за этой ловушки в Spectre почти 500 строк
считались готовыми и оставались английскими.

## Команды

```
python tools/check.py --build    проверить перевод и сборку
python tools/build.py            собрать .tlk в build/
python tools/build.py --install  собрать и положить в игру
python tools/mkmale.py           собрать правки под мужского Шепарда
python tools/build.py --male     собрать мужской вариант в build_male/
python tools/mkrelease.py v1.2   собрать архивы для релиза
python tools/lookup.py <слово>   найти термин в официальной локализации
```

## Новый мод: порядок работы

1. `python tools/dump.py <DLC>` — выгрузить текст мода из игры в `source/`.
2. `python tools/prep.py <stem>` — разложить: блоки данных отдельно,
   проза отдельно в `work/<stem>/prose_en.txt`.
3. Перевести прозу по частям, блоки данных собираются по образцу
   официального перевода автоматически.
4. `python tools/assemble.py <stem>` — собрать обратно в `translation/`.
5. `python tools/check.py` — проверить.

## Правки со стороны

Перевод и код ведёт только автор. Pull Request не принимаются — подробности
в `CONTRIBUTING.md`. От людей принимаются отзывы и сообщения об ошибках
через Issues.

В коммитах не ставить строки с упоминанием инструментов и соавторов.
