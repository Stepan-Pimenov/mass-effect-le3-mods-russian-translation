# Русификатор модов для Mass Effect 3 Legendary Edition

Русский перевод текста, который добавляют популярные моды ME3 Legendary Edition. Ванильный текст игры не меняется — переведено только то, чего в игре изначально не было.

> **English version: [README.en.md](README.en.md)**

Перевод выполнен «под ванилью»: терминология сверена с официальным русским переводом трилогии (Жнецы, Горн, СБЦ, ГОР, панацелин, названия планет, оружия и брони — всё как в игре). Имена собственные взяты из официального перевода LE1, LE2, LE3 и всех DLC, а не переведены на слух.

## Установка

### Способ 1 — программа с окном (рекомендуемый)

1. Со [страницы релизов](../../releases) скачивается архив `ME3LE-Russian-Mods-<версия>-full.zip` и распаковывается в любую папку.
2. Запускается **`ME3LE-Русификатор-модов.exe`**.
3. Программа сама находит игру, показывает список компонентов с галочками и ставит только отмеченные. Там же выбирается вариант перевода — **Шепард: женский / мужской** — и находится кнопка отката.

Компоненты, для которых соответствующий мод не установлен, отмечаются как недоступные — лишнего не поставится. Права администратора не нужны, если игра лежит не в `Program Files`.

Перед заменой каждого файла создаётся резервная копия `*_RUS.tlk.bak` — по ней работает кнопка **Удалить перевод**.

### Способ 2 — вручную

В архиве рядом лежит папка `dist/`, где файлы уже разложены в структуре игры. Содержимое нужного компонента копируется с заменой в

```
…\Mass Effect Legendary Edition\Game\ME3\BioGame\DLC\
```

Например, для EGM файл `DLC_MOD_EGM_RUS.tlk` должен оказаться в `DLC\DLC_MOD_EGM\CookedPCConsole\`.

Рядом с каждым файлом лежит такой же с `.male.tlk` — это вариант под мужского Шепарда. Чтобы поставить его вручную, нужно скопировать именно его и убрать из имени `.male`.

Для отдельных компонентов на странице релизов лежат небольшие архивы вида `ME3LE-Russian-EGM-<версия>.zip` — их содержимое распаковывается прямо в папку `DLC`.

### Способ 3 — из командной строки

Для тех, кому нужен скриптуемый вариант, в комплекте есть PowerShell-версия установщика:

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1 -Components EGM,Spectre -Silent
powershell -ExecutionPolicy Bypass -File install.ps1 -Components all -Male -Silent
powershell -ExecutionPolicy Bypass -File install.ps1 -GamePath "D:\Games\Mass Effect Legendary Edition"
powershell -ExecutionPolicy Bypass -File uninstall.ps1
```

Без параметров `install.ps1` работает в диалоговом режиме. Ключ `-English` переключает язык вывода, `-Male` ставит вариант под мужского Шепарда.

## Совместимость

**Порядок установки.** Русификатор ставится **последним**, после того как все моды разложены по папкам (после ME3Tweaks Mod Manager, ALOT, ALOV и прочего). Переустановка мода через менеджер возвращает его собственный английский `_RUS.tlk` — тогда установщик нужно запустить ещё раз.

**Текстурные моды** (ALOT, ALOV, A Lot of Videos) не конфликтуют: перевод не содержит текстур и не трогает `.pcc`. Порядок относительно них не важен.

**Другие русификаторы.** Ванильный `BIOGame_RUS.tlk` не затрагивается, поэтому перевод сочетается с любыми правками основного текста игры.

**Версии модов.** Перевод собран под версии из таблицы выше. На более новой версии мода он тоже встанет, но строки, добавленные после сборки, останутся английскими: неизвестные номера строк просто не подменяются, ничего не ломается. Если в моде поменяли нумерацию строк (случается редко, обычно при крупных переработках), часть текста может встать не на своё место — тогда стоит откатиться кнопкой **Удалить перевод** и завести Issue.

**Сохранения.** Перевод на них не влияет: меняется только текст. Ставить и убирать его можно в любой момент, в том числе посреди прохождения.

**Мультиплеер** третьей части не затрагивается.

## Как это сделано

В папке `tools/` лежат скрипты на Python, которыми всё собиралось:

* разбор и сборка бинарного формата `.tlk`, включая хаффмановское сжатие строк;
* извлечение официального перевода из LE1 (из UE3-пакетов `.pcc` со сжатием Oodle), LE2, LE3 и всех DLC — получился словарь примерно на 100 000 пар «оригинал → официальный русский»;
* автоподстановка официального перевода по точному совпадению, по нормализованному тексту, нечётким поиском, по началу строки и по абзацам. Моды часто берут ванильную статью кодекса и дописывают к ней свои абзацы, поэтому ванильная часть подставляется сама, а вручную переводится только новое;
* генераторы для однотипных строк настроек, названий оружия и блоков данных о планетах.

Сам перевод лежит в `translation/` — это JSON-файлы вида `"номер строки": "русский текст"`. Правки вносятся прямо там, после чего перевод пересобирается:

```bash
python tools/build.py            # собрать .tlk в build/
python tools/build.py --install  # собрать и сразу положить в игру
python tools/mkmale.py           # собрать правки под мужского Шепарда в translation_male/
python tools/build.py --male     # собрать мужской вариант в build_male/
python tools/mkrelease.py        # собрать архивы для релиза
```

Путь к игре берётся из переменной окружения `ME3LE_PATH` (корень игры) или `ME3LE_DLC`; если их нет — из значения по умолчанию в начале `tools/build.py`.

Приоритет при сборке: перевод из `translation/` → существующий русский текст мода → английский.

Установщик собирается из `tools/installer/Installer.cs` штатным компилятором Windows:

```powershell
powershell -ExecutionPolicy Bypass -File tools\build_installer.ps1
```

Двух папок в репозитории нет намеренно: `source/` (выгруженные тексты модов) и `reference/` (официальный перевод, извлечённый из самой игры) — это чужая интеллектуальная собственность. Они создаются локально из собственной копии игры:

```bash
python tools/dump.py             # выгрузить тексты установленных модов в source/
python tools/build_le1_ref.py    # словарь официального перевода LE1
python tools/build_le2_ref.py    # LE2
python tools/build_dlc_ref.py    # DLC LE3
```

## Обратная связь

Об ошибках и опечатках можно сообщать в [Issues](../../issues), указав мод и сам текст (или скриншот). Правки через Pull Request тоже приветствуются: достаточно изменить нужный файл в `translation/`, перевод пересоберётся из него.

Перевод делался без проверки каждой строки в игре, поэтому где-то возможны шероховатости в длине строк или падежах.
