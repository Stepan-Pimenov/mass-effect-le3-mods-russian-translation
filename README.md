# Русификатор модов для Mass Effect 3 Legendary Edition

Русский перевод текста, который добавляют популярные моды ME3 Legendary Edition. Ванильный текст игры не меняется — переведено только то, чего в игре изначально не было.

> **English version: [README.en.md](README.en.md)**

Перевод сделан «под ванилью»: вся терминология сверена с официальным русским переводом трилогии (Жнецы, Горн, СБЦ, ГОР, панацелин, названия планет, оружия и брони — всё как в игре). Имена собственные брались из официального перевода LE1, LE2, LE3 и всех DLC, а не переводились на слух.

## Установка

### Способ 1: установщик (проще всего)

1. Скачай архив из раздела [Releases](../../releases) и распакуй в любую папку.
2. Запусти **`Установить.bat`**.
3. Установщик сам найдёт игру, покажет список компонентов и поставит те, которые ты выберешь.

Компоненты, для которых соответствующий мод не установлен, в списке не появятся — лишнего не поставится.

Чтобы поставить конкретные компоненты без вопросов:

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1 -Components EGM,Spectre -Silent
```

Если игра лежит в нестандартном месте, путь можно указать вручную:

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1 -GamePath "D:\Games\Mass Effect Legendary Edition"
```

### Способ 2: вручную

Файлы лежат в `dist/<Компонент>/` уже в готовой структуре папок. Скопируй содержимое нужного компонента в

```
…\Mass Effect Legendary Edition\Game\ME3\BioGame\DLC\
```

с заменой. Например, для EGM файл `DLC_MOD_EGM_RUS.tlk` должен оказаться в
`DLC\DLC_MOD_EGM\CookedPCConsole\`.

### Удаление

Запусти **`Удалить.bat`** — установщик вернёт на место резервные копии (`*_RUS.tlk.bak`), которые он сделал перед заменой. Можно и просто удалить файлы `*_RUS.tlk` вручную, но тогда мод покажет текст по-английски.

## Требования

* Mass Effect Legendary Edition, часть **ME3**
* Установленные моды, которые ты хочешь русифицировать
* В игре выбран **русский язык**
* Windows PowerShell 5.1 (есть в любой Windows 10/11) — только для установщика

Перевод не зависит от версии моддинг-инструментов: это просто замена файла с текстом. Но если автор мода выпустит крупное обновление и добавит новые строки, они останутся английскими, пока перевод не обновят.

---

## Порядок установки относительно менеджера модов

Ставь русификатор **после** того, как все моды установлены и разложены по папкам (после ME3Tweaks Mod Manager, ALOT и прочего). Если потом переустановишь мод через менеджер, он положит свой английский `_RUS.tlk` обратно — просто запусти установщик снова.

## Как это сделано

В папке `tools/` лежат скрипты на Python, которыми всё собиралось:

* разбор и сборка бинарного формата `.tlk`, включая хаффмановское сжатие строк;
* извлечение официального перевода из LE1 (из UE3-пакетов `.pcc` со сжатием Oodle), LE2, LE3 и всех DLC — получился словарь примерно на 100 000 пар «оригинал → официальный русский»;
* автоподстановка официального перевода по точному совпадению, по нормализованному тексту, нечётким поиском, по началу строки и по абзацам. Моды часто берут ванильную статью кодекса и дописывают к ней свои абзацы, так что ванильная часть подставляется сама, а вручную переводится только новое;
* генераторы для однотипных строк настроек, названий оружия и блоков данных о планетах.

Сам перевод лежит в `translation/` — это JSON-файлы вида `"номер строки": "русский текст"`. Правки удобно вносить прямо там, а потом пересобрать:

```bash
python tools/build.py            # собрать .tlk в build/
python tools/build.py --install  # собрать и сразу положить в игру
```

Путь к игре берётся из переменной окружения `ME3LE_PATH` (корень игры) или `ME3LE_DLC`; если их нет — из значения по умолчанию в начале `tools/build.py`.

Приоритет при сборке: перевод из `translation/` → существующий русский текст мода → английский.

Двух папок в репозитории нет специально: `source/` (выгруженные тексты модов) и `reference/` (официальный перевод, извлечённый из самой игры) — это чужая интеллектуальная собственность. Они создаются локально из твоей собственной копии игры:

```bash
python tools/dump.py             # выгрузить тексты установленных модов в source/
python tools/build_le1_ref.py    # словарь официального перевода LE1
python tools/build_le2_ref.py    # LE2
python tools/build_dlc_ref.py    # DLC LE3
```

## Нашли ошибку или опечатку?

Открывай [Issue](../../issues) — укажи мод, где встретился текст, и сам текст (или скриншот). Правки через Pull Request тоже приветствуются: меняй нужный файл в `translation/`, перевод пересоберётся.

Перевод делался без проверки каждой строки в игре, так что где-то могли остаться шероховатости в длине строк или падежах — сообщайте, поправим.
